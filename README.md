# Connext — Professional Connection Platform (Frontend Demo)

## Run
1. Install Node.js (LTS).
2. Extract this ZIP and open the `professional-connect` folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Demo login
Use any username and any password, then choose Customer, Professional, or Admin. Everything is frontend-only and demo data persists in browser localStorage.

## Included demo flows
- Responsive futuristic dark UI with blue/violet accents.
- Search/filter professional directory and open profiles.
- Demo login for all three roles.
- Paid chat simulated checkout; no real payment is taken.
- Chat messages persist locally in this browser.
- Meeting space selection and booking confirmation/history.
- Professional profile/services editing demo.
- Admin overview of demo professionals, bookings, and payment records.
- Buttons and navigation have working demo actions.

## Not production-ready
No backend, secure authentication, database, real-time cross-user chat, real payment gateway, identity verification, or actual room booking is connected. Never use this demo to collect real payment details. Connect a backend and payment provider before launch.
